## FOXmin 0.1.1

FOXmin now runs on Intel Macs too.

### Changes
- **Universal app**: one download for Apple Silicon and Intel Macs (0.1.0 only opened on Apple Silicon).
- Nothing else changes: same features, same settings. If you already have 0.1.0, just replace the app in Applications; you won't need to grant the Accessibility permission again.

### Install
1. Download `FOXmin-0.1.1.zip`, double-click it and drag **FOXmin** to **Applications**.
2. The first time, **right-click → Open** (macOS warns because the app isn't from the App Store). If it still won't open, go to **System Settings → Privacy & Security** and click **Open Anyway**.
3. Give it the **Accessibility** permission when macOS asks.

Requires macOS 13 or newer, on Apple Silicon or Intel.
