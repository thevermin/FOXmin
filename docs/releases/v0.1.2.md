## FOXmin 0.1.2

More reliable clicks on background windows.

### Fixes
- **No more accidental text selection.** If you clicked again because the window seemed slow to react, both clicks reached the app together as a double-click, selecting a word. Now that extra click is ignored, while a real double-click still works.
- **Tiny mouse movements during a click no longer select text.** Only a real drag is replayed as a drag.
- **Fewer ignored clicks.** FOXmin now waits until the app itself knows it's active before sending your click, so apps that discard the activating click no longer swallow it.
- **Faster in Chrome and Electron apps.** FOXmin used to wait the maximum time on them every time, so the Fast setting made no difference.

### Install
Download `FOXmin-0.1.2.zip`, double-click it and replace the app in **Applications**. If you already use FOXmin, you won't need to grant the Accessibility permission again.
